# Write Feature Specification

1. **Context Check:**
   - Do you have a clear idea or design from a previous `brainstorm` session?
   - If no, ask the user for the feature description or requirements.

2. **Trigger Skill:** Use the `writing-features` skill.
   - Create a new file in `.docs/features/` based on `.docs/features/FEATURES_template.md`.
   - Focus on Requirements, Acceptance Criteria, and the High-Level Implementation Plan.
   - **Do NOT** write the implementation code yet.

3. **Review:** Ask the user to review the generated Feature Specification.

4. **Next Step:** Once approved, suggest using the `execute-feature` command to build it.
