# Brainstorming Session

1. **Ask User:** "What idea or feature would you like to brainstorm today?"
   - (If the user already provided a topic in the prompt, skip this step).

2. **Trigger Skill:** Use the `brainstorming` skill to guide the session.
   - Follow the skill's instructions to refine the idea into a design.
   - Remember the goal is to define enough context to eventually create a **Feature Specification**.

3. **Next Step:** Once brainstorming is complete, suggest using the `write-feature` command to formalize it.
